# MyMarket Recursive Validator

Selenium + TestNG ავტომატიზაციის ფრეიმვორკი **mymarket.ge**-ის განცხადების დამატების გვერდისთვის.  
მთავარი მიზანია კატეგორიების იერარქიის რეკურსიული გავლა და შემოწმება (სათაურები, ბრენდები, უკან დაბრუნება).

## რას ამოწმებს

- ყველა კატეგორია/ქვეკატეგორია არსებობს კატალოგში
- არჩეული კატეგორიის სათაური ემთხვევა preview-ს
- ბრენდების სია სწორია (როცა საჭიროა)
- „უკან“ ღილაკი სწორად აბრუნებს წინა დონეს

ტესტები მუშაობს **გაყიდვა / ყიდვა / იჯარა / სერვისი** სექციებზე.

## ტექნოლოგიები

- Java 16
- Selenium 4 + WebDriverManager
- TestNG (parallel methods)
- Guice (Dependency Injection)
- ExtentReports
- Gson / org.json
- Lombok
